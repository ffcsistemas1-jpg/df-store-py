# DF Store PY — versión completa

Proyecto Next.js + Supabase de DF Store PY.

## Flujo del carrito
- Agregar al carrito guarda el producto y permite seguir navegando.
- Comprar agrega el producto y lleva al carrito.
- El carrito se conserva en el navegador y sincroniza con Supabase cuando está disponible.

## Estructura
El contenido de esta carpeta debe copiarse a la raíz del repositorio GitHub.
